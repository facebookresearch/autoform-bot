# Thesis roadmap

The long-term goal is to identify and formalize the reusable mathematical core
of the thesis. The initial milestone is intentionally narrower: audit and
decompose the “Infimum Loss” chapter before committing to theorem-level plans
for the remaining chapters.

## High-level map

1. **Considerations on Learning Theory**
   - Fast Rates for Structured Prediction
   - Exponential Convergence Rates for SVM
2. **Learning with Partial Supervision**
   - [Full Supervision](full-supervision/README.md) — supporting Lean chapter
   - [Infimum Loss](infimum-loss/README.md) — initial article DAG
   - Disambiguation Framework
   - Laplacian Regularization
3. **Active Labeling**
   - Streaming Stochastic Gradients

## Current milestone

Formalize the definitions of eligibility and non-ambiguity, the results that
grow from them, and the supporting full-supervision construction before
supervision recovery. The
[coverage page](../coverage/README.md) records what the project does and does
not yet claim.
